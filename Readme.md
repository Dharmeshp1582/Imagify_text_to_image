# Imagify - Text to Image Generator

Imagify is a full-stack web application that transforms text prompts into stunning AI-generated images. Users can register, log in, purchase credits, and generate images using a simple and intuitive interface.

## Features

- **AI Text-to-Image Generation:** Enter a prompt and get a unique image generated by AI.
- **User Authentication:** Secure registration and login with JWT and cookies.
- **Credit System:** Users need credits to generate images. Credits can be purchased via Razorpay integration.
- **Responsive UI:** Built with React, Tailwind CSS, and Vite for a fast and modern experience.
- **Testimonials & Plans:** See what users say and choose from flexible credit plans.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB, Mongoose
- **Authentication:** JWT, Cookies
- **Payments:** Razorpay
- **AI API:** ClipDrop Text-to-Image API

## Project Structure

```
client/      # React frontend
server/      # Node.js/Express backend
```

## Getting Started

### Prerequisites

- Node.js & npm
- MongoDB database
- Razorpay account (for payment integration)
- ClipDrop API key

### Environment Variables

Create `.env` files in both `client/` and `server/` directories. See the provided `.env` files for required variables.

### Installation

#### Backend

```sh
cd server
npm install
npm run dev
```

#### Frontend

```sh
cd client
npm install
npm run dev
```

### Usage

1. Register or log in.
2. Purchase credits via the "Buy Credits" page.
3. Enter a text prompt and generate your image.
4. Download or share your generated images.
